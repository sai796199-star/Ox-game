# NOIR.XO — Premium Tic Tac Toe

A responsive, editable browser game built with plain HTML, CSS and JavaScript. No framework or installation required.

## Run it
1. Extract `premium_ox_game.zip`.
2. Open the `premium_ox_game` folder.
3. Double-click `index.html` to play in Chrome, Edge, Firefox or another modern browser.

## Edit it
- `index.html` — page content, labels, game layout and controls.
- `style.css` — colors, typography, spacing, responsive design and visual effects.
- `script.js` — game rules, AI, scores, sounds and button behavior.

## Included
- Black + gold premium responsive interface
- Player vs Computer and Two Players modes
- Easy, Medium and Hard AI
- Win, draw and loss session statistics
- Win-rate progress bar
- Sound toggle and light/dark theme toggle
- No backend, account or paid software required

## Customize the gold color
At the top of `style.css`, edit `--gold: #d7b56d` and `--gold2: #f0d99d`.

## Notes
- Stats are session-only and reset when the page is refreshed.
- Online multiplayer, accounts, global leaderboards and ad integration are not included in this starter version; they need a backend and service configuration.
- Google Fonts are loaded online; system fallback fonts are used if unavailable.
